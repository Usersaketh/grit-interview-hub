# Implementation status

## Completed

- **Core Architecture & Tooling**: Next.js 15 App Router modular monolith, strict TypeScript (`tsc --noEmit`), ESLint (`--max-warnings=0`), Zod boundary schemas, standalone output configuration, middleware safe fallback when unconfigured.
- **Public Student Signup (`/signup`, `POST /api/v1/auth/signup`)**: Full signup form with client/server validation, password visibility toggles, email verification vs immediate session UX, rate limiting (`429`), API-level rejection of privileged role fields (`403`), and DB trigger `handle_new_auth_user` + `ensure_student_profile` enforcing `STUDENT`-only role provisioning.
- **Invitation-Only Interviewer Onboarding (`/operations/invitations`, `/invitations/accept`, `/api/v1/admin/invitations*`, `/api/v1/invitations/*`)**: Cryptographic 256-bit tokens (SHA-256 hashed at rest), single-use expiring invitations, email-mismatch protection, safe distinction between new accounts and existing-account sign-in acceptance, and role locked to `INTERVIEWER`.
- **Student Interviewer Directory & Real Slot Discovery (`/student/interviews/book`, `GET /api/v1/student/interviewers`, `GET /api/v1/student/slots`)**: 3-step booking flow replacing manual UUID entry with badge eligibility check, interviewer browsing with profile/tags/timezones, and DST-safe real slot generation (`computeBookableSlots`) excluding busy windows, unavailable overrides, minimum notice, and `retake_after` cooldowns.
- **Transactional Student Cancellation & Atomic Rescheduling (`/student/interviews/[id]`, `POST /api/v1/student/interviews/[id]/{cancel,reschedule}`)**: Cancel modal and live reschedule slot picker enforcing 2-hour cutoff, mandatory reasons, GiST exclusion overlap protection, and persisted `interview_reschedule_history`.
- **Complete Interviewer Lifecycle & Attendance (`/interviewer/interviews/[id]`, `GET/POST .../start`, `awaiting-outcome`, `attendance`, `result`)**: Workspace detail RPC displaying assigned candidate identity, session start, completion to `AWAITING_OUTCOME`, attendance/no-show tracking, and immutable idempotent evaluation submission.
- **Operations Certification Queue, Audit Explorer & Dashboard (`/operations*`)**: Live operations KPIs (including `pendingCertifications` and `pendingInvitations`), searchable certification approval queue & detail page with confirmation modal, malpractice case workflow, and staff-only paginated Audit Explorer with JSON previous/new diffs backed by immutable `audit_logs` trigger.
- **Verification**: Vitest unit suite across 8 test files (109 tests), `node:test` frontend domain suite (13 tests), `next build`, `compile_applet`, `lint_applet`, live HTTP security boundary checks, and headless Chromium Playwright CLI verification across desktop/mobile and light/dark themes.
